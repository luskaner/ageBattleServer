# Use cases

## General

* Enable further open-source development to improve features and fix bugs.
* Not having to purchase AoE II: DE to have access to the latest (yet still outdated) public release.
* Native builds for non-Windows OSes and non-x86_64 architectures.

## LAN lobby

* Replacing AoE III: DE - The Baltic Powers buggy LAN implementation
* Announcing on all local network interfaces without relying on workarounds (*like Age Server does*).

## Age Server related

* Allow to be embedded as a library in the Server simplifying operations.
* Enable replay uploading.
